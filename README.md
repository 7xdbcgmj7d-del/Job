# AI Job Copilot

> 面向转行求职者的 AI 求职决策助手，帮助用户从岗位 JD 解析、简历匹配、面试准备到投递追踪，完成 AI 驱动的求职闭环。

## 一句话定位

AI Job Copilot 不是单纯的求职记录工具，而是面向转行求职者、应届生和产品经理求职者的 AI 求职决策助手。它通过岗位管理、简历管理、AI 匹配分析、面试准备和投递复盘，帮助用户从「盲目海投」转向「有策略地投递」。

## 目标用户

- **转行 AI PM / 产品经理的求职者**：有项目经历，但不知道如何包装简历、判断岗位匹配度。
- **应届生 / 实习求职者**：投递岗位多，但缺少求职进度管理和面试准备方法。
- **产品经理岗位求职者**：需要围绕不同 JD 调整简历表达、准备项目深挖问题。
- **缺少求职策略的用户**：不知道哪些岗位值得优先投递，也不知道失败后如何复盘。

## 核心问题

传统求职记录工具只能帮助用户「记住投了哪些岗位」，但不能回答求职中更关键的问题：

- 这个岗位 JD 到底在要求什么能力？
- 我的简历和这个岗位匹配吗？
- 投递前简历应该怎么改？
- 面试前应该重点准备哪些问题？
- 面试失败后，下次应该优化什么？

因此，本项目希望在求职管理工具的基础上，引入 AI 分析能力，帮助用户完成「岗位理解 → 简历匹配 → 投递决策 → 面试准备 → 复盘优化」的完整闭环。

## 核心功能

### 1. 首页看板

用于快速查看整体求职进度，包括总投递数、待面试数量、Offer 数量、转化率、状态分布和近期面试动态。

### 2. 岗位管理

支持按照求职状态管理岗位，例如待投递、已投递、筛选中、待面试、Offer、已淘汰、已撤回等。用户可以记录公司、职位、薪资范围、当前状态和下一步行动。

### 3. 简历管理

支持管理多个简历版本，例如产品经理通用版、AI PM 版本、增长产品版本等。用户可以设置默认简历、记录简历标签、维护在线简历链接。

### 4. 面试管理

支持记录面试时间、公司、岗位、面试轮次、面试官、会议链接、复盘内容和自我评分，帮助用户沉淀面试经验。

### 5. 设置与数据管理

支持 AI 配置、面试问题库、数据导入导出等能力，方便后续扩展 Prompt 管理、评测集管理和 Bad Case 记录。

## AI 能力设计

当前项目正在从「求职记录工具」升级为「AI 求职决策助手」，规划中的 AI 能力包括：

### 1. JD 解析

输入岗位 JD，AI 自动提取：

- 岗位核心职责
- 必备技能
- 加分项
- 隐含能力要求
- 岗位风险点
- 适合候选人类型

### 2. 简历匹配分析

输入「岗位 JD + 用户简历」，AI 输出结构化匹配结果：

- 匹配度评分
- 匹配等级
- 匹配优势
- 明显短板
- 投递建议
- 投递前优化动作

### 3. 简历优化建议

根据目标岗位，AI 给出针对性的简历修改建议，包括需要强化的经历、需要补充的关键词、表达过弱的项目描述和可替换的简历表达。

### 4. 面试准备生成

根据 JD 和简历，AI 生成可能被问到的问题，包括业务问题、项目深挖问题、AI 产品问题、数据分析问题和回答准备方向。

### 5. 面试复盘分析

根据面试记录和反馈，AI 帮助用户归因失败原因，沉淀问题库，并生成下次面试前的优化动作。

## 产品闭环

```text
添加岗位
  ↓
粘贴岗位 JD
  ↓
选择目标简历
  ↓
AI 生成匹配分析
  ↓
AI 给出投递建议与简历优化动作
  ↓
投递并进入面试管理
  ↓
AI 生成面试准备问题
  ↓
面试后记录反馈
  ↓
AI 复盘失败原因并更新求职策略
```

## 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS
- **UI 组件**：Radix UI、lucide-react
- **表单处理**：React Hook Form、Zod
- **数据可视化**：Recharts
- **数据库 ORM**：Prisma
- **邮件服务**：Resend
- **开发工具**：ESLint、TypeScript ESLint

## 运行方式

### 1. 克隆项目

```bash
git clone https://github.com/Xzhou-duo/Job.git
cd Job
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发环境

```bash
npm run dev
```

默认本地访问地址：

```text
http://localhost:5173
```

### 4. 构建生产版本

```bash
npm run build
```

### 5. 本地预览生产构建

```bash
npm run preview
```

## 项目价值

这个项目的目标不是简单复刻一个求职进度管理工具，而是通过 AI 能力解决求职者在岗位判断、简历优化、面试准备和复盘迭代中的关键问题。

它体现的 AI PM 能力包括：

- 从用户痛点出发定义产品定位
- 将 AI 能力嵌入具体业务流程
- 设计结构化 AI 输入与输出
- 建立 Prompt、评测集和 Bad Case 迭代机制
- 用产品闭环而不是单点功能展示 AI 价值
